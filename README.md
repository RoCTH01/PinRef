# PinRef

A Chrome extension that adds a private, local-first reference library on top of Pinterest: Tags, Notes, search and Trash for Pins you save, without mirroring or changing your Pinterest account.

- Load `extension/` as an unpacked extension (Chrome 142+). Usage and verification: [extension/README.md](extension/README.md).
- Domain language: [CONTEXT.md](CONTEXT.md). Decisions: [docs/adr/](docs/adr/). Product behavior: [docs/product/crud-decisions.md](docs/product/crud-decisions.md).
- Tests: `npm test`, `npm run typecheck`, `npm run test:browser`.
